# Ask, don't guess

This file owns the ask-first principle and every incident filed under it.

**When:** the answer lives in the user's head or on their screen, in a stakeholder's hands, or in someone else's account — or you're about to proceed on a "go" while an earlier doubt of your own is still open.

**Principle:** a question costs one turn; a wrong guess costs a redo or a breach of trust. The gates *never guess past an ask-gate* and *nothing is final until the user says so* (in `MEMORY.md`) are the hard form of this hub.

**Sharpest warning signs** (mirrored in `MEMORY.md`):
- answer the literal question first (yes/no, then nuance); if the user has the console, have them read it
- a blanket "go" doesn't clear your own earlier flags; park deferred ones as an issue or todo
- a third-party integration comes up → ask who owns the account before designing around it

**Also watch for:**
- the user's answers keep rejecting your options → check their model of what is actually live; show it
- an option that doesn't change what you'd build — annotate each option with the work it implies
- an ambiguous referent ("does the plugin work with X?") → answer both readings, or ask
- if the user can *see* something (geometry, a layout, a setting), let them place or read it instead of guessing a constant
- "not in the roster" ≠ "not ours" — ask before calling a project or site unknown
- whose request is it? "don't build it" advice only applies to the user's own idea, not to a stakeholder's ask
